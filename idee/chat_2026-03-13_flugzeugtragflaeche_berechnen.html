Ja 👍 Es gibt tatsächlich aerodynamische Formeln, mit denen man abschätzen kann, wie viel Gewicht eine Tragfläche tragen kann. Für Modellflugzeuge benutzt man meistens die Auftriebsgleichung.

Auftriebsgleichung (Lift)

[ L = \tfrac{1}{2} \rho v^2 S C_L ]

Bedeutung der Variablen:

  • L – Auftriebskraft (Newton)
  • ρ (rho) – Luftdichte (≈ 1,225 kg/m³ auf Meereshöhe)
  • v – Geschwindigkeit des Flugzeugs relativ zur Luft (m/s)
  • S – Tragflächenfläche (m²)
  • Cₗ – Auftriebsbeiwert (hängt stark vom Stellwinkel / Anstellwinkel und Profil ab)

Damit ein Flugzeug fliegt gilt ungefähr:

Auftrieb = Gewicht

Einfluss des Stellwinkels

Der Stellwinkel (Anstellwinkel) beeinflusst den Auftriebsbeiwert Cₗ.

Typische Werte für Modellflugzeuge:

Anstellwinkel Cₗ ungefähr
0° 0.2 – 0.3
4° 0.6 – 0.8
8° 1.0 – 1.2
>12–15° Strömungsabriss

Mehr Winkel → mehr Auftrieb → bis zum Stall.

Beispiel (Modellflugzeug)

Angenommen:

  • Geschwindigkeit 10 m/s (~36 km/h)
  • Tragfläche 0,5 m²
  • Cₗ = 0,8

Dann:

[ L = 0{,}5 \cdot 1{,}225 \cdot 10^2 \cdot 0{,}5 \cdot 0{,}8 ]

≈ 24,5 N

Das entspricht etwa

2,5 kg Gewicht.

Sehr wichtige Erkenntnis für Modellflug

Für Modellflugzeuge nutzt man oft eine einfache Daumenregel:

Flächenbelastung

[ \text{Gewicht} / \text{Flügelfläche} ]

Typische Werte:

Flugzeugtyp Flächenbelastung
Segler 5–10 kg/m²
Trainer Modellflug 10–15 kg/m²
schnelle Modelle 15–25 kg/m²

Beispiel: Fläche 0,4 m²

 gutes Trainingsmodell:

0,4 × 12 kg/m² ≈ 4,8 kg max

Ja 👍 In Python kannst du die Auftriebsgleichung sehr einfach als Funktion schreiben.

Python-Formel

def lift(rho, v, S, C_L):
    L = 0.5 * rho * v**2 * S * C_L
    return L

Parameter:

  • rho – Luftdichte (kg/m³), z.B. 1.225
  • v – Geschwindigkeit (m/s)
  • S – Tragflächenfläche (m²)
  • C_L – Auftriebsbeiwert

Beispielrechnung

rho = 1.225 # Luftdichte
v = 10 # Geschwindigkeit m/s
S = 0.5 # Fläche m²
C_L = 0.8 # Auftriebsbeiwert

L = lift(rho, v, S, C_L)

print("Auftrieb:", L, "Newton")
print("Tragbares Gewicht:", L/9.81, "kg")

Ausgabe etwa:

Auftrieb: 24.5 Newton
Tragbares Gewicht: 2.5 kg

Wenn du Kevlar-Folie (Aramidfolie) zum Bespannen von Modellflugflächen benutzt, gibt es ein wichtiges Problem: Kevlar schrumpft kaum durch Wärme. Deshalb spannt sie sich mit einem Föhn oft gar nicht oder nur minimal.

Temperaturverhalten von Kevlar

Kevlarfasern (z.B. in Aramidfolien) haben:

  • keine nennenswerte thermische Schrumpfung
  • sehr hohe Temperaturbeständigkeit

Typische Werte:

Eigenschaft Wert
Temperaturbeständig ~300–400 °C
Thermische Schrumpfung praktisch 0 %
Schmelzpunkt keiner (zersetzt sich erst >450 °C)

👉 Deshalb funktioniert das Heißspannen wie bei Modellbau-Folie nicht.

Warum andere Modellbaufolien funktionieren

Typische Bespannfolien (z.B. Oracover oder Monokote) bestehen aus Polyester (PET).

Diese haben:

  • Schrumpftemperatur: ca. 120–160 °C
  • Schrumpfung: 2–5 %

Dadurch spannt sich die Fläche automatisch.

Was bei Kevlar-Bespannung üblich ist

Bei Kevlar- oder Glasgewebe wird die Spannung normalerweise nicht durch Hitze erzeugt, sondern durch:

  1. mechanisches Spannen beim Aufkleben
  2. Harz (Epoxid)
  3. Lack/Dope der beim Trocknen schrumpft

Typische Methoden:

1️⃣ Epoxid + Kevlargewebe - Gewebe auflegen - mit Epoxid tränken - beim Aushärten wird es steif

2️⃣ Spannlack (klassischer Modellbau) - Bespannpapier oder Gewebe - mehrere Schichten Spannlack - Lack schrumpft beim Trocknen

Warum dein Föhn nicht funktioniert

Ein normaler Föhn:

  • 60–100 °C Lufttemperatur

Das reicht nur für PET-Modellbaufolie, aber selbst dort oft knapp.

Bei Kevlarfolie bringt Hitze praktisch keine Spannung.

  1. Nasenleiste

import numpy as np
import matplotlib.pyplot as plt

def naca4(m,p,t,c=1,points=50):
    """NACA4-digit generator, returns x,y arrays scaled to chord c"""
    x = np.linspace(0, c, points)
    yt = 5*t*c*(0.2969*np.sqrt(x/c) - 0.1260*(x/c) - 0.3516*(x/c)**2 + 0.2843*(x/c)**3 - 0.1015*(x/c)**4)
    yc = np.zeros_like(x)
    for i in range(points):
        if x[i] < p*c:
            yc[i] = m/p**2*(2*p*(x[i]/c) - (x[i]/c)**2)
        else:
            yc[i] = m/(1-p)**2*((1-2*p) + 2*p*(x[i]/c) - (x[i]/c)**2)
    xu = x - yt*np.sin(np.arctan(np.gradient(yc,x)))
    yu = yc + yt*np.cos(np.arctan(np.gradient(yc,x)))
    xl = x + yt*np.sin(np.arctan(np.gradient(yc,x)))
    yl = yc - yt*np.cos(np.arctan(np.gradient(yc,x)))
    return np.concatenate([xu[::-1], xl[1:]]), np.concatenate([yu[::-1], yl[1:]])

    return np.concatenate([xu[::-1], xl[1:]]), np.concatenate([yu[::-1], yl[1:]])

🧠 1️⃣ Die „physikalisch optimale“ Form

Die theoretisch beste Form ist:

  • minimaler induzierter Widerstand
  • beste Gleitzahl
  • gleichmäßige Auftriebsverteilung

👉 Problem: schwer zu bauen 😄

🔧 2️⃣ Praktische Lösung: Trapezflügel

Deshalb nimmt man fast immer:

👉 Trapezflügel

Definiert durch: - Wurzeltiefe (c_root) - Spitzentiefe (c_tip) - Spannweite (b)

📐 3️⃣ Wichtiger Parameter: Zuspitzungsverhältnis

lambda = c_tip / c_root

✅ 4️⃣ Optimale Werte (Daumenregeln)

Für deinen Segler:

Flugzeugtyp λ (Tip/Root)
Anfänger / stabil 0.5 – 0.7
guter Segler 0.4 – 0.6 ✅
Hochleistung 0.3 – 0.5
rechteckig (einfach) 1.0

👉 Empfehlung für euch:

lambda ≈ 0.5

📏 5️⃣ Berechnung aus Fläche

Gegeben: - Fläche (S) - Spannweite (b) - Verhältnis λ

Dann:

S = (c_root + c_tip)/2 * b

mit

c_tip = lambda * c_root

➡️ Einsetzen:

S = (c_root + lambda*c_root)/2 * b

S = c_root * (1 + lambda)/2 * b

➡️ nach c_root auflösen:

c_root = 2*S / (b*(1+lambda))

Dann:

c_tip = lambda * c_root

🧮 6️⃣ Beispiel für euren Segler

Gegeben: - S = 15 dm² = 0.15 m² - b = 0.7 m - λ = 0.5

👉 Rechnung:

c_root = 2 * 0.15 / (0.7 * 1.5)
       ≈ 0.286 m ≈ 28.6 cm

c_tip = 0.5 * 28.6 ≈ 14.3 cm

👉 Für euren Flieger:

  • Wurzeltiefe: ~29 cm
  • Spitzentiefe: ~14 cm
  • Verhältnis: 2:1

Das ist:

✅ aerodynamisch gut ✅ stabil ✅ leicht zu bauen

Warum nicht rechteckig?

Warum nicht zu spitz?

  • schlechter bei niedriger Geschwindigkeit
